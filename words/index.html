Tra cứu

Tìm kiếm và mở thẻ từ tương ứng để xem nghĩa và các dạng khác của từ.

Information noun Thông tin

InformverbThông báo, báo tin

InformativeAdjectivecung cấp nhiều thông tin bổ ích, lý thú

InformedAdjectivecó hiểu biết, được thông tin đầy đủ, am hiểu

InformationalAdjectivethuộc về thông tin, dùng để cung cấp thông tin

UninformativeAdjectivekhông cung cấp nhiều thông tin, vô bổ

InformativelyAdverbmột cách cung cấp nhiều thông tin, hữu ích

I need more information about this project

Computer noun Máy tính

ComputingnounNgành khoa học máy tính

ComputerizedadjectiveĐược máy tính hóa

The computer is running slowly today.

Software noun Phần mềm

Software engineernoun phraseKỹ sư phần mềm

He works as a software developer.

Hardware noun Phần cứng

Hardware componentsnoun phraseCác thành phần phần cứng

The hardware needs to be upgraded.

Network noun Mạng lưới

NetworkingnounKết nối mạng, giao tiếp mạng

NetworkedadjectiveĐược kết nối mạng

The computers are connected through a local network.

Database noun Cơ sở dữ liệu

DatanounDữ liệu

Database managementnoun phraseQuản lý cơ sở dữ liệu

All user information is stored in the database.

Algorithm noun Thuật toán

AlgorithmicadjectiveLiên quan đến thuật toán

The algorithm improves search accuracy.

Application noun Ứng dụng

AppnounỨng dụng (viết tắt)

ApplyverbÁp dụng, ứng dụng

This mobile application helps users learn faster.

Program noun Chương trình

ProgrammingnounLập trình

ProgrammernounLập trình viên

She is learning computer programming.

System noun Hệ thống

SystematicadjectiveCó hệ thống

SystematicallyadverbMột cách có hệ thống

The system crashed unexpectedly.

Server noun Máy chủ

ServeverbPhục vụ, cung cấp

Server-sideadjectivePhía máy chủ

The server is down for maintenance.

Client noun Máy khách, người dùng

Client-sideadjectivePhía người dùng

The client connects to the server via the internet.

Interface noun Giao diện

User interfacenoun phraseGiao diện người dùng

The new interface is more user-friendly.
