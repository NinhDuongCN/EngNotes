Grammar guide

Comparisons

So sánh bằng, hơn, nhất và các cấu trúc đặc biệt.

01 / Nền tảng

Câu so sánh dùng để làm gì?

Cấu trúc so sánh giúp đối chiếu người, vật hoặc hành động theo một đặc điểm cụ thể.

Chọn đúng dạng

  • So sánh bằng: hai đối tượng có mức độ tương đương.
  • So sánh hơn: một đối tượng có mức độ cao hơn.
  • So sánh nhất: cao nhất trong một nhóm.
  • Tính từ ngắn thường thêm -er/-est; tính từ dài dùng more/most.
Quick note

Good, better, best

Một số tính từ có dạng so sánh bất quy tắc.

good → better → best
bad → worse → worst
02 / Tra cứu

Các cấu trúc so sánh

Tìm theo dạng so sánh hoặc tính từ.

01

Equal Comparison
So sánh bằng

Dùng khi: hai đối tượng có cùng mức độ.

Ví dụ: This car is as fast as that one.

+ as + adjective + as
02

Comparative
So sánh hơn

Dùng khi: so sánh hai đối tượng.

Ví dụ: This test is easier than the last one.

+ adj-er/more + adj + than
03

Superlative
So sánh nhất

Dùng khi: nói đối tượng nổi bật nhất trong một nhóm.

Ví dụ: It is the most useful tool.

+ the + adj-est/most + adj
04

The more..., the more...
Càng... càng...

Dùng khi: một thay đổi kéo theo một thay đổi khác.

Ví dụ: The more you read, the more you learn.

+ The more + clause, the more + clause
