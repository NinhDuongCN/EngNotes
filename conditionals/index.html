Grammar guide

Conditionals

Câu điều kiện: giả thiết, kết quả và những tình huống giả định.

01 / Nền tảng

Câu điều kiện là gì?

Câu điều kiện diễn tả một điều kiện và kết quả có thể xảy ra từ điều kiện đó. Mệnh đề bắt đầu bằng if có thể đứng trước hoặc sau mệnh đề chính.

Hai mệnh đề trong câu

  • If-clause: nêu điều kiện giả thiết.
  • Main clause: nêu kết quả.
  • Nếu mệnh đề if đứng đầu câu, dùng dấu phẩy để ngăn cách.
  • Không dùng will ngay sau if trong câu điều kiện thông thường.
Quick note

Cách đọc công thức

If giới thiệu điều kiện; mệnh đề còn lại nêu kết quả.

If + condition, result
Result + if + condition
02 / Tra cứu

Các loại câu điều kiện

Tìm theo loại câu, ý nghĩa hoặc công thức.

01

Zero Conditional
Loại 0

Dùng khi: nói về sự thật hiển nhiên, quy luật hoặc kết quả luôn đúng.

Ví dụ: If you heat ice, it melts.

+ If + S + V(s/es), S + V(s/es)
02

First Conditional
Loại 1

Dùng khi: nói về điều kiện có khả năng xảy ra ở hiện tại hoặc tương lai.

Ví dụ: If it rains, we will stay home.

+ If + S + V(s/es), S + will + V
03

Second Conditional
Loại 2

Dùng khi: nói về tình huống không có thật hoặc khó xảy ra ở hiện tại.

Ví dụ: If I had more time, I would travel.

+ If + S + V2, S + would + V
04

Third Conditional
Loại 3

Dùng khi: nói về điều đã không xảy ra trong quá khứ và kết quả giả định.

Ví dụ: If she had studied, she would have passed.

+ If + S + had + V3, S + would have + V3
05

Mixed Conditional
Hỗn hợp

Dùng khi: điều kiện và kết quả thuộc hai mốc thời gian khác nhau.

Ví dụ: If I had listened, I would be safer now.

+ If + S + had + V3, S + would + V
06

Unless
Trừ khi

Dùng khi: thay cho if...not để diễn tả một điều kiện phủ định.

Ví dụ: You will miss the bus unless you hurry.

+ Unless + S + V, S + will + V
Không tìm thấy câu điều kiện phù hợp.
